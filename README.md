# 🤖 Makine Öğrenmesi Ders Notları

Bu depo, **Makine Öğrenmesi** dersi kapsamında hazırlanan 14 haftalık ders notlarını, teorik anlatımları, temel matematiksel kavramları, algoritma incelemelerini ve Python uygulamalarını içermektedir.

🌐 **Ders Web Sitesi:** [fatihavcu.github.io/makine_ogrenmesi_ders](https://fatihavcu.github.io/makine_ogrenmesi_ders/)  
💻 **GitHub Reposu:** [github.com/fatihavcu/makine_ogrenmesi_ders](https://github.com/fatihavcu/makine_ogrenmesi_ders)

---

## 🎯 Dersin Amacı ve İçeriği

Bu dersin temel amacı; veri bilimi ve yapay zekanın kalbini oluşturan makine öğrenmesi algoritmalarının matematiksel altyapısını anlamak, denetimli ve denetimsiz öğrenme yöntemlerini öğrenmek ve gerçek hayat verileri üzerinde modelleme uygulamaları geliştirmektir.

Ders boyunca veri ön işlemeden model değerlendirmeye, regresyondan sınıflandırma ve kümeleme algoritmalarına kadar geniş bir yelpazede konular ele alınmaktadır.

---

## 📚 14 Haftalık Ders Planı

| Hafta | Konu | Temal İçerik ve Açıklama |
| :---: | :--- | :--- |
| **01** | 🚀 **Dersin Tanıtımı** | Makine öğrenmesine giriş, temel kavramlar, yapay zekadaki yeri |
| **02** | 📊 **Veri Tanıma ve Tanımsal İstatistikler** | Veri türleri, merkezi eğilim/dağılım ölçüleri, veri görselleştirme |
| **03** | 🎯 **Denetimli Algoritmalar ve Hata Kavramı** | Denetimli öğrenme mantığı, hedef değişken, MSE, MAE vb. hata metrikleri |
| **04** | ⚖️ **Varyans-Yanlılık ve Çapraz Doğrulama** | Bias-Variance Tradeoff, Overfitting/Underfitting, Cross-Validation |
| **05** | 📈 **Doğrusal Regresyon (Linear Regression)** | Basit ve Çoklu Doğrusal Regresyon, En Küçük Kareler (OLS) Yöntemi |
| **06** | 📉 **Lojistik Regresyon ve Sınıflandırma Hatası** | Sınıflandırma mantığı, Sigmoid fonksiyonu, Karmaşıklık Matrisi (Confusion Matrix) |
| **07** | 🧪 **Sınıflandırma Verisi ile Uygulama** | Veri seti üzerinde uçtan uca sınıflandırma modeli geliştirme |
| **08** | 📝 **Ara Sınav / Sunum** | Ara sınav değerlendirmesi ve proje sunumları |
| **09** | 🔍 **K-En Yakın Komşu (k-NN)** | Uzaklık metrikleri (Minkowski, Euclidean), k parametresi seçimi |
| **10** | 🌳 **Karar Ağaçları (Decision Trees)** | Entropi, Gini Indeksi, Bilgi Kazancı (Information Gain) ve Ağaç Budama |
| **11** | 🌲 **Rassal Ormanlar (Random Forests)** | Bagging, Ensemble Learning (Topluluk Öğrenmesi) mantığı |
| **12** | 🎯 **Destek Vektör Makineleri (SVM)** | Hiper düzlem, Marjin optimizasyonu, Çekirdek (Kernel) Hilesi |
| **13** | 📉 **Temel Bileşen Analizi (PCA)** | Boyut indirgeme, Özdeğer/Özvektör kavramları ve Varyans korunumu |
| **14** | 🗂️ **Kümeleme (Clustering)** | Denetimsiz öğrenme, K-Means algoritması, Hiyerarşik Kümeleme |

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler

Ders Notlarında ve uygulamalarda ağırlıklı olarak aşağıdaki Python ekosistemi araçları kullanılmaktadır:

* **Programlama Dili:** Python 3.x
* **Veri Analizi ve İşleme:** `pandas`, `numpy`
* **Veri Görselleştirme:** `matplotlib`, `seaborn`
* **Makine Öğrenmesi:** `scikit-learn`
* **Ortam:** Jupyter Notebook / Google Colab / VS Code

## 💻 Kullanım ve Yerel Kurulum

Ders notlarını bilgisayarınıza klonlayıp çalıştırmak için:

1. **Repoyu klonlayın:**
   ```bash
   git clone https://github.com/fatihavcu/makine_ogrenmesi_ders.git
   cd makine_ogrenmesi_ders
   ```

2. **Gerekli Python paketlerini yükleyin:**
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```

3. **Jupyter Notebook'u başlatın:**
   ```bash
   jupyter notebook
   ```
